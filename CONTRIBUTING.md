# Contributing to AutoDetect

Thanks for your interest in AutoDetect! 🎯

## How to Contribute

I welcome suggestions and feedback. I review all contributions carefully to maintain code quality and project direction.

### ✅ Preferred ways to contribute:

1. **Open a Discussion** (strongly preferred)
   - Suggest new features
   - Report bugs (with reproduction steps)
   - Share ideas for improvements
   - Ask questions about usage
   
   **Link**: [GitHub Discussions](https://github.com/Antonoof/AutoDetect/discussions)

2. **Share examples or use cases**
   - How are you using AutoDetect?
   - What datasets worked well?
   - Performance benchmarks you've seen

3. **Report documentation issues**
   - Unclear API descriptions
   - Missing examples
   - Typos or formatting errors

### ❌ Not accepted at this time:

- **Direct Pull Requests** without prior discussion
- **Large code changes** without coordination
- **Untested or breaking changes**

## Process for Code Contributions

If you have a code change in mind:

1. **Open a Discussion first** describing:
   - What problem you're solving
   - Your proposed solution
   - Why it's valuable

2. **Wait for a response** — I'll let you know if it fits the roadmap

3. **Only if approved** — then you can:
   - Fork the repository
   - Create a branch
   - Submit a Pull Request

This ensures we don't waste your time on changes I might not be able to merge.

## Reporting Bugs

Open a **Discussion** with label `bug` and include:

```markdown
**Bug description**
What happened?

**To reproduce**
Minimal code example:

from autodetect import AutoDetect
ad = AutoDetect(...)

**Environment**
- AutoDetect version: [e.g., 0.1.0]
- Python version: [e.g., 3.10]
- PyTorch version: [e.g., 2.0.1]
- OS: [e.g., Ubuntu 22.04]
```
